# Solar Energy Data Analysis - Mini Project

## Project Description
This project analyzes solar energy data to understand patterns, efficiency, and weather impact.  
Used Python for data analysis and visualisation.

## Files in this Project
- **main.py** - Main file to run the analysis
- **data_loader.py** - Load the CSV data
- **visualisation.py** - Create graphs and charts
- **economic.py** - Economic analysis of solar data
- **statistics.py** - Statistical calculations
- **solar_analysis.py** - Core solar calculations
- **weather_analysis.py** - Weather impact analysis
- **figures/** - All generated graphs and charts
- **solar_energy_data_fixed(1).csv** - Dataset used

## How to Run
1. Install Python 3.x
2. Install Pycharm
3. Install required libraries: `pip install pandas, matplotlib seaborn`
4. Run the main file: `python main.py`

## Results
All the answers are shown in the run wihndow. 
All graphs are saved in the `figures` folder.
